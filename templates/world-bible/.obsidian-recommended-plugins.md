# Obsidian Recommended Plugins Setup Guide

To unlock the full power of your Scriptorium World Bible, install the following 4 core community plugins in Obsidian.

---

## Step 1: Enable Community Plugins in Obsidian
1. Open Obsidian.
2. Click the gear icon (**Settings**) in the bottom-left corner.
3. Select **Community plugins** on the left sidebar.
4. Click **Turn on community plugins** (disables Restricted Mode).

---

## Step 2: Install & Enable the 4 Essential Plugins

Click **Browse** in the Community plugins tab, search for each plugin by name, click **Install**, and then click **Enable**:

### 1. Dataview (by blacksmithgu)
- **What it does**: Turns your Markdown notes into a queryable database. Automatically populates character tables, location listings, and timeline views.
- **Settings configuration**:
  - In *Settings -> Dataview*: Ensure **Enable JavaScript Queries** and **Enable Inline Queries** are enabled.

### 2. Templater (by SilentVoid13)
- **What it does**: Automates template creation with file title variables, dates, and dynamic placeholders (`<% tp.file.title %>`).
- **Settings configuration**:
  - In *Settings -> Templater*:
    - Set **Template folder location** to: `Templates`
    - Turn on **Trigger Templater on new file creation**.

### 3. Kanban (by mgmeyers)
- **What it does**: Creates visual Trello-style boards directly from Markdown files. Ideal for tracking chapter drafting stages (Outline -> Draft -> Edit -> Complete).
- **Usage**: Create a new note `Writing-Board.md` and right-click -> "Open as Kanban Board".

### 4. Excalidraw (by Zsolt Viczian)
- **What it does**: Seamless infinite whiteboard for hand-drawn flowcharts, relationship graphs, tactical battle maps, and world sketchpad notes.

---

## Step 3: Vault Appearance & Theme (Optional)
- Recommended Themes for long writing sessions:
  - **Minimal** (Clean, distraction-free)
  - **Things** or **Nord** (High legibility, soothing dark mode)
